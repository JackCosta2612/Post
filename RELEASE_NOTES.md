Post 0.2.2

- A brief, subtle transition when switching inboxes, labels or filters. Reduce Motion disables it.
- Email text stays padded inside its background when original email colors are enabled, in light and dark mode.
- Label badges exclude mail in Trash and Spam.
- Submerge is the default new-mail sound. Select another sound in Notifications settings to preview it.
- More reliable hand cursors over clickable controls.

This release includes source code. Build and install using the README instructions. Post’s Check for updates opens this release page; installation remains manual. Each person supplies their own Google Desktop OAuth client.
